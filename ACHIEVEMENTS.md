## Higher tiers

Community-reported total thresholds, including the base tier:

- Pull Shark: 2, 16, 128, and 1,024 merged pull requests.
- Pair Extraordinaire: 1, 10, 24, and 48 coauthored merged pull requests.
- Galaxy Brain: 2, 8, 16, and 32 accepted answers.
- Starstruck: 16, 128, 512, and 4,096 stars on a repository.

## Limits and other badges

Arctic Code Vault Contributor and Mars 2020 Contributor were tied to historical events and cannot be earned through new contributions. Heart On Your Sleeve and Open Sourcerer are listed as disabled in the community reference. Finishing Touch is community-reported for GitHub UI quality contributions; public eligibility has not been independently confirmed here. Proxima achievements are internal to GitHub.

GitHub also lists program badges such as Pro, Developer Program Member, Campus Expert, Security Bug Bounty Hunter, and Security advisory credit. Each requires its corresponding subscription, participation, or accepted security contribution.

GitHub controls awarding and timing. Keep contributions useful, credit actual collaborators, and let stars and accepted answers reflect other people's choices.
